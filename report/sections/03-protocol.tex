\subsection{Разбиение и кандидаты}

Признаки на дату \(t\) используют только события с датой меньше \(t\).
История обновляется после завершения каждого дня, веса модели при оценке
фиксированы. На train обучаются модели, на search подбираются параметры
и признаки, на confirm проверяется выбранное решение.
Test оценивается после сохранения \code{selection.lock.json}

В запрос входят все доступные положительные объекты дня и 50 уникальных
контрольных объектов: 25 выбираются равномерно, ещё 25 с весом
\(N_i(t)^{0.75}\), где \(N_i(t)\)
обозначает число прошлых записей объекта. Уже просмотренные пользователем
объекты исключаются. Будущие просмотры при выборе контролей не учитываются,
а отсутствие просмотра в день запроса не считается достоверным отказом

Каталог состоит из объектов, встречавшихся у выбранных пользователей
до даты запроса. В test доступны 12\,968 из 13\,224 исходных целевых записей,
или 98.06\%. Метрики рассчитываются только для доступных целей
и выбранных кандидатов
