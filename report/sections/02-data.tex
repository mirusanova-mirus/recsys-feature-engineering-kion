\section{Данные и протокол}

Из \href{https://github.com/irsafilo/KION_DATASET}{KION} равномерно выбраны
30\,000 пользователей с seed 42. Сохранены все их 169\,946 записей за
период с 13 марта по 22 августа 2021 года, включая истории из одной записи.
В выборке 7\,254 объекта, медианная длина истории составляет 2 события.
Использован архив \code{data_original.zip}, версия источника и SHA-256
записаны в \code{data/SOURCE_MANIFEST.json}

Запрос соответствует паре «пользователь, день». Объекты с записью просмотра
в этот день получают метку 1, выбранные контрольные объекты получают метку 0.
Поле \code{last_watch_dt} содержит дату последнего просмотра пары,
поэтому ранние повторные просмотры восстановить нельзя.
Поля \code{total_dur} и \code{watched_pct} исключены из признаков,
поскольку содержат информацию о целевом просмотре
