\section{Чувствительность к выбору кандидатов}

При равномерном выборе всех 50 контрольных объектов NDCG@10 ручного
набора равен 0.68320, автоотбора 0.68729.
Разность 0.00409 имеет интервал \([+0.00157,+0.00665]\).
Абсолютные значения нельзя напрямую сопоставлять с результатами
на смешанном пуле, поскольку меняется сложность кандидатов

Для проверки на полном каталоге равномерно выбраны 210 тестовых запросов
без возвращения с seed 2026. Для них ранжируются все доступные объекты,
кроме уже просмотренных пользователем

Разность автоотбора и ручного набора составляет 0.00456.
Интервал \([-0.01240,+0.02253]\) включает ноль,
поэтому преимущество автоотбора здесь не подтверждается.
Популярность получает более высокий NDCG@10.
Результат на смешанных кандидатах характеризует переранжирование
этого пула и не переносится напрямую на весь каталог

Возможная причина расхождения связана с распределением контролей:
модель обучается отличать целевые объекты от заданной смеси,
а при ранжировании каталога состав конкурирующих объектов меняется.
Это гипотеза, отдельно её механизм не проверялся.
Каталожные результаты не использовались для настройки
