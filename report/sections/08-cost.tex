\section{Затраты и воспроизведение}

Основной эксперимент выполнен на CPU с шестью потоками на обучение.
Построение основных таблиц признаков заняло 114.3 секунды,
суммарное время обучения 26 моделей составило 62.6 минуты.
Пиковая резидентная память основного процесса составила 4\,021 МиБ

Часть дополнительных моделей обучалась параллельно, поэтому сумма
времени обучения не равна времени выполнения всего эксперимента.
Для одной даты на вложенных выборках из 1\,000, 10\,000 и 30\,000
пользователей построение всех признаков заняло 0.13, 0.53 и 1.35 секунды.
Это один локальный замер, оснований для экстраполяции
на миллиарды событий нет

Реализация на pandas повторно группирует историю для каждого дня
и окна. Для большего масштаба нужны инкрементальные счётчики,
удаление устаревших событий из окон и отдельный этап отбора кандидатов
перед ранжированием
