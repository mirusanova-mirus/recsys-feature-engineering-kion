# Редактирование отчёта в LaTeX

Откройте **main.tex** в Codex, TeXstudio или Overleaf. Это отдельный многофайловый
проект; для Overleaf загрузите всё содержимое папки report и выберите main.tex.
По умолчанию используется pdfLaTeX, также предусмотрены XeLaTeX/LuaLaTeX.

- `metadata.tex` — название, автор (впишите своё имя), дата.
- `sections/` — полный текст, таблицы и формулы. Файлы идут в порядке отчёта.
- `sections/body.tex` — порядок подключения разделов.
- `figures/` — локальные копии всех рисунков; внешние папки для сборки не нужны.
- `preamble.tex` — шрифты, поля, цвета, ссылки и оформление.
- `report.pdf` — собранная версия этих исходников.
- `source_map.json` — соответствие разделов исходному Markdown при первом переносе.

Редактируйте `.tex` напрямую. Команды обучения и генерации Markdown/PDF в корне
репозитория **не перезаписывают** эту папку. При обновлении эксперимента числа
и рисунки в LaTeX нужно обновить осознанно. `REPORT.md` сохраняется как исходная
версия исследовательского отчёта; обратная синхронизация из LaTeX не выполняется.

Сборка из этой папки с установленным TeX Live/MacTeX/MiKTeX:

```bash
make
```

Из корня репозитория: `make latex`. Python, данные и обученные модели для сборки
отчёта не нужны. В Codex открывайте папку report: редактор покажет исходники и
предпросмотр PDF. Подчёркивания и проценты в обычном тексте пишите как `\_`
и `\%`; математику — в `\(...\)` или окружениях equation/align.

Шрифты для XeLaTeX/LuaLaTeX включены в `fonts/`; лицензия — `fonts/LICENSE_DEJAVU`.
