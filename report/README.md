## Структура

| Путь | Содержание |
| --- | --- |
| `sections/body.tex` | Порядок разделов |
| `sections/*.tex` | Текст, таблицы и формулы |
| `metadata.tex` | Автор, название и дата |
| `preamble.tex` | Шрифты, поля и заголовки |
| `figures/` | Рисунки |
| `fonts/` | Локальные CMU-шрифты и лицензия |

## Сборка

Основной движок XeLaTeX, локальные шрифты включены в проект

```sh
make latex
```

Команда выполняется из корня репозитория.
Из папки `report/` используйте `make`.
В Overleaf выберите `main.tex` и XeLaTeX

`make latex` сохраняет PDF в `report/report.pdf`

Код экспериментов не перезаписывает папку `report/`.
При новых измерениях числа и рисунки в LaTeX обновляются отдельно
